Autochecker Matching

매칭 프로세스Matching Process

카메라를 옮기거나 다른 카메라로 바꿔도 — 각 카메라의 intrinsic 과 cam_to_base 만 있으면 검사는 성립한다. 그런데 이 둘의 쓰임이 다르다: anchor 추정은 카메라 프레임 안에서 닫혀 cam_to_base 가 필요 없고, cam_to_base 는 safe zone 판정에 쓰인다. Even if the camera is moved or swapped, inspection works as long as each camera's intrinsics and cam_to_base are known. But the two play different roles: anchor estimation is self-contained in the camera frame and needs no cam_to_base, while cam_to_base is used for the safe-zone check.

cam_to_base 불필요cam_to_base not needed

anchor L/R/U 추정anchor L/R/U estimation

매칭이 상대포즈(템플릿 ↔ 현재 화면)를 구하고, 템플릿의 anchor 정의점을 그 포즈로 변환하면 곧바로 현재 카메라 프레임의 3D 가 나온다. Matching gives a relative pose (template ↔ current view); applying it to the template's anchor points yields 3D directly in the current camera frame.

매칭match→ 상대포즈relative pose→ anchor 변환anchor transform→ 카메라 프레임 3Dcamera-frame 3D

전 과정이 카메라 프레임 안에서 닫혀 있다 — 카메라가 base 와 어떤 관계인지 몰라도 된다. 단, 카메라 교체를 고려해 각 카메라의 intrinsic 은 필요하다(역투영·undistort 용). The whole process is closed within the camera frame — it need not know the camera's relation to base. Each camera's intrinsics are still required (for back-projection / undistort).

cam_to_base 필요cam_to_base needed

safe zone 판정safe-zone check

세이프존은 teaching 때 로봇 base 기준으로 정의된 공간상 고정 영역이다. 카메라가 이동하면 "teaching 카메라 좌표의 존"과 "runtime 카메라 좌표의 anchor"는 서로 다른 프레임이라 직접 비교할 수 없다. The safe zone is a fixed region defined in the robot base frame at teaching time. If the camera moves, the zone (in teaching-camera coords) and the anchor (in runtime-camera coords) live in different frames and can't be compared directly.

anchor (매칭 기반)anchor (from matching)→ base
zone (로봇 좌표계)zone (robot frame)→ base

그래서 둘 다 base 로 올려서 비교한다 — anchor 는 runtime cam_to_base, zone 은 teaching cam_to_base 로 변환한다. So both are lifted to base — the anchor via runtime cam_to_base, the zone via teaching cam_to_base.

정리: 카메라를 옮기거나 교체해도 intrinsic + cam_to_base 만 갖추면 된다. anchor 추정 자체는 cam_to_base 없이도 카메라 프레임에서 성립하고, cam_to_base 는 base 기준 safe zone 판정(과 base 표현 산출물)에 쓰인다. Summary: moving or swapping the camera is fine as long as intrinsics + cam_to_base are available. Anchor estimation works in the camera frame without cam_to_base; cam_to_base is used for the base-frame safe-zone check (and base-frame outputs).
